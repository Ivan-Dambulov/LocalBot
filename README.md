# LocalBot

**Private, local AI for your desktop.**

LocalBot is a lightweight desktop application that lets you run GGUF language models fully offline on your own machine. No cloud, no API keys, no data leaving your computer.

> **⚠️ Currently in Beta**  
> LocalBot is under active development. Expect bugs, performance improvements, and breaking changes as the project evolves. Feedback and contributions are very welcome.

---

## Features

- **Fully local inference** — Powered by [llama-cpp-python](https://github.com/abetlen/llama-cpp-python)
- **GGUF model support** — Run popular open-source models offline
- **Streaming responses** — Token-by-token generation for a natural chat experience
- **Model Manager** — Download models directly from Hugging Face
- **Automatic hardware optimization**
  - Detects CPU, GPU, and available memory
  - Recommends optimal GPU layers and context size
- **Broad hardware support**
  - NVIDIA (CUDA)
  - AMD
  - Apple Silicon
  - CPU-only mode
- **Persistent conversations** — Stored locally with SQLite
- **Modern UI** — Clean interface with Dark & Light mode (CustomTkinter)
- **Cross-platform** — Works on Windows, macOS, and Linux
- **WebSearch
